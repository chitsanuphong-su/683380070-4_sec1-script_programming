# Web Scraping Intro

A simple web scraping project using Python, `requests`, and `BeautifulSoup4`.

## Features
* Fetches HTML content from target URL.
* Parses and extracts book & chapter titles.

## How to Run
1. Activate virtual environment: `venv\Scripts\activate`
2. Install requirements: `pip install requests beautifulsoup4`
3. Run scraper: `python main.py`
